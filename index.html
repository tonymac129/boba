What Is Web Dev?

Web dev is the creative process of building real websites, web apps, or games with technologies like HTML, CSS, and JavaScript.

HTML

HTML, or Hypertext Markup Language, is, as its name suggests, a text markup language that defines the structure and content of a webpage using tags like <h1> and <div>.

CSS

CSS, or Cascading Style Sheets, is a stylesheet language that's responsible for defining the styling and appearance of elements by setting properties such as color, size, and background.

JavaScript

JavaScript (not Java!) is a programming language used to add functionality and interactivity to websites by detecting events, processing logic, and doing a lot of really cool stuff (that we'll cover in future workshops!).
